# Academic portfolio website — Tasnimul Alam Taz

A responsive static academic portfolio based on the CV, research statement, and teaching statement supplied October 13, 2026.

## Preview
Open `index.html` in a browser. The three documents under `documents/` are linked throughout the site.

## Publish
- GitHub Pages: create a repository, upload the **contents** of this folder to the repository root, then enable Pages in repository Settings → Pages (deploy from main branch/root).
- Netlify or Cloudflare Pages: upload this folder as a static site.

## Edit
All copy, styling, and interactions are contained in `index.html`. The header uses an abstract TT monogram rather than a personal headshot. You can replace it with a photo later.

Before publishing, double-check publication details, links, and research metrics against your latest records.
